# TriLayer Lab
Учебный проект для курсовой «Анализ взаимодействия между языками разметки, стилей и сценариев в единой среде разработки».

## Состав
- `index.html`: семантические элементы и формы
- `src/style.css`: оформление, переменные темы, адаптивные медиазапросы
- `src/app.js`: обработчики DOM, ввод, фильтр, смена темы, localStorage
- `src/model.js`: чистые функции проверки и изменения данных
- `tests/model.test.js`: 35 тестов Node.js

## Запуск
В корне проекта выполните `python -m http.server 8000` и откройте http://localhost:8000.
Тесты: `npm test` (Node.js версии 20+).

## Ограничения
Проект предназначен для локального демонстрационного запуска. Нет серверной БД, авторизации и синхронизации между пользователями. Unit-тесты чистых функций не заменяют ручную проверку DOM, доступности и адаптивности.
